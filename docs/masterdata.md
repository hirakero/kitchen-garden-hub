## 野菜マスターデータ（MVP対象・9種）

| 野菜 | 特徴 |
|---|---|
| ニラ | 多年草・ほぼ放置・何年も収穫可能 |
| 万能ネギ | 根元から再生・庭にあってたまに取ってくる系 |
| リーフレタス | 春・秋に種まき幅広 |
| 小松菜 | 春〜秋ほぼ通年・種まき〜収穫の幅が広い |
| ミニトマト | 夏の定番・使用頻度高い |
| きゅうり | 夏に大量収穫・使用頻度高い |
| タマネギ | 半年以上保存可能 |
| ジャガイモ | 数ヶ月保存可能 |
| 二十日大根 | 20〜30日で収穫・通年栽培可能 |

### マスターデータの管理方針

- **MVP**: 開発者が管理（ユーザーはリストから選ぶだけ）
- **将来フェーズ**: ユーザーが水やり頻度などをカスタマイズできるように拡張

## マスターデータ定義（野菜9種）

### ミニトマト

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき | 発芽を確認した | 水やり（毎日） |
| 育苗 | 本葉4〜5枚になった | 水やり（2日ごと）、液肥（7日ごと） |
| 定植 | 定植した | 支柱立て（定植時・一回限り）、水やり（2日ごと） |
| 生育・着果 | 実が赤くなり始めた | 水やり（2日ごと）、芽かき（7日ごと）、追肥（14日ごと） |
| 収穫期 | 収穫を終了した | 水やり（2日ごと）、収穫（3日ごと）、追肥（14日ごと） |

### きゅうり

| ステージ | チェックポイント | タスク |
|---|---|---|
| 定植（苗から） | 活着を確認した | 支柱立て（定植時・一回限り）、水やり（毎日） |
| 生育 | 最初の雌花が開花した | 水やり（毎日）、追肥（7日ごと）、誘引（3日ごと） |
| 収穫期 | 収穫を終了した | 水やり（毎日）、収穫（2日ごと）、追肥（7日ごと） |

### 小松菜

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき | 発芽を確認した | 水やり（毎日） |
| 生育 | 草丈15〜20cmになった | 水やり（2日ごと）、間引き（7日後・一回限り） |
| 収穫 | 収穫を終了した | 収穫（随時） |

### リーフレタス

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき | 発芽を確認した | 水やり（毎日） |
| 育苗・間引き | 本葉5〜6枚になった | 水やり（2日ごと）、間引き（7日後・一回限り） |
| 収穫期 | 収穫を終了した | 水やり（2日ごと）、外葉収穫（4日ごと） |

### 二十日大根

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき | 発芽を確認した | 水やり（毎日） |
| 生育 | 根が1〜2cmに膨らんだ | 水やり（毎日）、間引き（5日後・一回限り） |
| 収穫 | 収穫を終了した | 収穫 |

### ニラ

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき・活着 | 発芽・活着を確認した | 水やり（2日ごと） |
| 生育 | 草丈20cm以上になった | 水やり（3日ごと）、追肥（30日ごと） |
| 収穫期（多年草） | 株を休ませる（秋） | 水やり（3日ごと）、追肥（30日ごと）、収穫（30日ごと） |

### 万能ネギ

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種まき・活着 | 発芽・活着を確認した | 水やり（2日ごと） |
| 生育 | 草丈20cm以上になった | 水やり（3日ごと）、追肥（21日ごと） |
| 収穫期 | 株を処分した | 水やり（3日ごと）、追肥（21日ごと）、収穫（根元3cm残し） |

### タマネギ

| ステージ | チェックポイント | タスク |
|---|---|---|
| 育苗 | 苗が鉛筆ほどの太さになった | 水やり（2日ごと） |
| 定植 | 活着を確認した | 定植（一回限り）、水やり（3日ごと） |
| 越冬・生育 | 葉が倒れ始めた（収穫サイン） | 追肥（30日ごと・2回）、観察（14日ごと） |
| 収穫・乾燥 | 乾燥・保管完了 | 収穫（一回限り）、乾燥（収穫3日後・一回限り） |

### ジャガイモ

| ステージ | チェックポイント | タスク |
|---|---|---|
| 種芋植え付け | 芽が出てきた | 植え付け（一回限り） |
| 発芽・生育 | 草丈20〜30cmになった | 水やり（5日ごと）、芽かき（14日後・一回限り） |
| 土寄せ・追肥 | 花が咲いた（または葉が枯れ始めた） | 土寄せ（一回限り）、追肥（一回限り）、水やり（5日ごと） |
| 収穫 | 収穫・保管完了 | 収穫（一回限り）、乾燥（収穫翌日・一回限り） |
